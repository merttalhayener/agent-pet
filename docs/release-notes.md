# Agent Pet v0.20.0 — Follow workflows and subagents

## What’s new

- **See inside the work.** VS Code's Claude panel doesn't show workflow progress, so Agent Pet does. Click the chevron on a running chat to list its workflow phases and every subagent with its status, model, tokens and time.
- **Progress at a glance.** Squares under the timer fill as agents finish, and the subtitle names the current phase and agent: `Fix · verify · 9/10 agents`.
- **Stopped work no longer lingers.** A workflow or agent stopped with TaskStop leaves the list, and its chat can complete.
- **Still local and private.** Only labels, phase names, model, token counts and times are kept. Prompts, results and scripts are never stored.

Includes custom pets and the shared chat panel for Codex, Claude Code and the official Google Antigravity VS Code extension.

## Install

Download `agent-pet-marketplace-0.20.0-darwin-arm64.vsix` below. In VS Code, choose **Extensions → … → Install from VSIX…**, then reload the window when your active work has finished.

Requires **Apple Silicon, macOS 26+ and VS Code 1.96.2+**.
