# Agent Pet v0.19.4 — See what Claude is running

## What’s new

- **Know what is running.** A Claude Code chat that is waiting on subagents now names them: `Agent: Review changes`, `Workflow: release-audit` or `6 agents · Check batch 5`. Hover the row to see the newest ones.
- **Privacy kept.** Agent Pet keeps only each agent's short description or workflow name while it runs. Prompts, scripts and summaries are never stored.
- **Background work stays running.** Since 0.19.3, a chat with background agents or a workflow stays running until that work reports back.

Includes custom pets and the shared chat panel for Codex, Claude Code and the official Google Antigravity VS Code extension.

## Install

Download `agent-pet-marketplace-0.19.4-darwin-arm64.vsix` below. In VS Code, choose **Extensions → … → Install from VSIX…**, then reload the window when your active work has finished.

Requires **Apple Silicon, macOS 26+ and VS Code 1.96.2+**.
