First public beta of Codex Pet Panel: a floating desktop companion for Codex in VS Code.

Download the attached `.vsix`, then install it using **VS Code → Extensions → ⋯ → Install from VSIX…**. Run **Codex Pet: Show Desktop Pet** from the Command Palette.

**Requires Apple Silicon, macOS 26+, and the official Codex VS Code extension.** This is an independent community project. The interface is currently Turkish.

Includes per-chat status and navigation, elapsed time, completion animation and optional sound, pending-question indicators, pinning, compact mode, appearance controls, snapping, and a global hide/show shortcut (**Ctrl+Option+Cmd+P**).

This beta is not Developer ID signed/notarized. Pet sprite sheets are loaded from the installed Codex extension and are not included in the download. See the README for current limitations and licensing status.
