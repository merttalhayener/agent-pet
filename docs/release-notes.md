Agent Pet 0.5.2 removes the old **Pet** section beneath the Codex chat. Agent Pet now uses its floating desktop panel only.

The README has a shorter feature overview, normal/compact/waiting previews, and a support matrix.

**Upgrade:** install the attached `.vsix`, then reload your VS Code window once to unload the old sidebar. Desktop preferences are preserved. **Agent Pet: Open Pet** and **Agent Pet: Show Desktop Pet** both open the floating pet.

Requires **Apple Silicon, macOS 26+, and Codex in VS Code**. Other agents and platforms are not supported yet. The beta helper is not Developer ID signed/notarized.
